## 1. Data Classification Schema <a name='section-1'></a>

**Level 1: Public**: Press releases, published blog posts.
**Level 2: Internal**: SOPs, Organizational Charts, Slack chatter.
**Level 3: Confidential**: Client Strategy Decks, Unreleased Creatives, Campaign Reports.
**Level 4: Restricted**: PII, Financial Records, Authentication Tokens, Private Keys.

## 2. Encryption Standards <a name='section-2'></a>

AES-256 for Data at Rest. TLS 1.3 for Data in Transit. No exceptions.

## 3. Data Retention <a name='section-3'></a>

Social media transcripts: 7 Years. Metadata: 3 Years. Temporary Cache: 24 Hours.

## 4. Clean Desk / Clean Screen <a name='section-4'></a>

Workstations must lock after 5 minutes of inactivity. No client data on personal mobile devices.
